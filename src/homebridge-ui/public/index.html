⚠️ Incompatible v4 Configuration Detected

Your config.json appears to be in the v4 format (using credentials and options.devices fields). This format is not compatible with v5 or newer of the SwitchBot plugin. Devices will not be recognised until the config is updated.

Please update your config to the v5 format:

  • Move credentials.token → openApiToken (top level)
  • Move credentials.secret → openApiSecret (top level)
  • Move options.devices → devices (top level)
  • Rename per-device connectionType → connectionPreference
  • Remove the credentials and options wrapper objects

See the Migration Guide for full details.
