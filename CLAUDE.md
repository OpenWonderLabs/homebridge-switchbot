# homebridge-switchbot

The project guide is shared with Copilot and imported here. It covers reference priority, branch
targeting, following node-switchbot changes, commands, structure and pitfalls:

@.github/copilot-instructions.md

## Claude-specific notes

- Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).
- If the right target branch is unclear, ask before opening the PR.
- PR description: what changed, why (link the node-switchbot PR/release), and any config migration
  users need.
